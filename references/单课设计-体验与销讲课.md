# 体验与销讲课：教学和产品说明分开设计

## 适用与前提

仅当用户明确要求体验课、销讲或介绍后续产品时使用，并先读[通用底座](单课教学设计通用底座.md)。输入包括体验课当堂学习终点、后续产品及真实权益、适合与不适合谁、价格/期限/报名方式、可用案例证据、师资及反馈方式。信息未确认就标“待核”，不从参考案例搬价格、名额、疗效、客户结果或合同承诺；也不要求用户先自行设计销售流程。普通交付课不自动调用本页。

## 教学组织决策

1. **定当堂结果。** 学员不购买也应完成本课明确承诺的知识、体验或练习；写出具体任务、材料、判断依据和可行反馈。体验只是一次特定条件下的观察，不等于长期效果。
2. **定承接的必要性。** 如果体验后确有后续产品，说明它额外提供什么、适用条件与限制是什么，和当堂交付有何不同。用户未授权产品介绍时结束在教学，不额外制造购买关卡。
3. **安排清楚的转换。** 设计者可在教学完成后集中介绍，或在必要的教学块后明确标识产品说明，再回到教学；选择取决于本课目标与承诺。说明听众可以如何提问、比较或自行决定；未知价格等用待核占位，不编造紧迫或承诺。
4. **核每项证据与反馈能力。** 案例可证明什么、缺什么；谁负责回答哪类问题；人数和场景是否允许个体反馈。健康、身体动作等由相应专业人员审核，明确停止/调整及适配条件；不要把个人体感当疗效，也不借课堂促销替代就医建议。
5. **收束。** 回答本课起始问题、提供适用的自查或下一步，并把产品咨询入口与参加条件写清楚；不能把课程的关键教学藏在付费承接后面。

## 交付格式

在环节表中标注每段是“教学/体验”“产品说明”或“回顾/问答”，写明具体教学任务、学员动作与反馈，以及已核实的产品信息或待核项；为可选产品说明预留时间，但不套用任何来源的销售比例。对体验课和产品各自列出一句适用边界。

## 操作或功法体验课：从原课观察到可用设计

`TRIAL-B` 的转写可见准备、带练、询问感受和再次练习，也可见复习旧内容后再进入新内容。可把它们作为**功能选项**而非固定动作或课时模板：

| 模块 | 为当前课程作出的设计决定 | 当堂可观察到什么 |
|---|---|---|
| 定目标和准备 | 明确学员今天要体验或学会的具体动作；交代场地、准备、可暂停或调整的条件。 | 学员知道要做什么及何时停止；无法参与者有经专业审核的替代或退出方式。 |
| 示范与分步 | 教师示范一个适合本课的真实动作或任务，解释关键步骤；只教准备时明确称准备，不冒充完整技能。 | 学员能指出关键步骤或自行对照示范。 |
| 带练、反馈、再练 | 留实际练习时间，邀请学员描述自己能观察到的感受或困难；根据现场/录播条件安排抽样回应、自查与必要的再练。 | 学员可说出本次做了什么、哪里需要调整；个体感受不等于疗效或诊断。 |
| 收束与承接 | 对照本课目标回顾并给出合适的练习或下一步；有后续课时说明它与本课的关系。 | 学员能复述本课重点及下一步，不依赖购买才能获得已承诺内容。 |

一节学习课不必包含所有模块，也不照搬原课动作数量。`TRIAL-B` 转写可见产品说明后再次进入带练，这支持“产品说明后仍可回到真实教学”的一个选择，不证明这种顺序促成成交。用户明确要求销讲时，可在完成当堂主要教学后安排真实产品信息、适配条件及自愿提问，再按需要回到教学或结束；未知权益与价格写待核，不沿用原课名额、价格或时间比例。

原课有把不适或疲劳解释为特定身体问题的说法，**不可移作诊断、疗效或继续练习的依据**。动作适配、停止与替代路径由合格专业人员按人群和交付方式审核；相关运动可能存在不适或伤害风险，参见 [NCCIH 安全说明](https://www.nccih.nih.gov/health/chronic-pain-and-complementary-health-approaches-usefulness-and-safety)。

## 可借鉴的案例，不能照搬的结论

- `TRIAL-A` 同时有逐字稿和抽样分析。前者可核到讲解、产品和报名说明相互穿插；旧分析把转化启动放在更晚位置，与原稿中的价格和报名操作不一致。只借“辨认教学和产品说明的功能及实际位置”来设计，不继承其时间占比、医疗说法或成交效果。
- `TRIAL-B` 有课程转写与二手分析，支持上述有限课堂组织观察；转写不随本技能分发。原音未经认证，不将转写当作原视频认证，也不把身体反应解释为健康改善。

证据层级与定位见[来源与证据状态](单课设计来源与证据状态.md)。
