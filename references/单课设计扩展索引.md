# 单课设计扩展索引

这是课程体系设计之后的可选下游入口。**先有已定课程框架，或用户明确授意使用本轮建议框架，并明确要求单课教学设计**，才使用。用户一次要求框架和单课时，先完成必要的框架及路线选择；已授权继续的，不为单课重复确认。独立的一节课先交代本课定位、起终点和交付条件，不虚构系列。

## 先选课要完成的事

下游执行者先读[单课教学设计通用底座](单课教学设计通用底座.md)，再按实际难点读下面对应参考；可以组合，但不把每种方式都塞进一课。索引与参考会告诉执行者怎么设计，来源分类和溯源见[来源与证据状态](单课设计来源与证据状态.md)。

| 本课主要要解决什么 | 加读与选用方式 |
|---|---|
| 让学员理解概念、用模型解释问题 | [知识与概念课](单课设计-知识与概念课.md)：根据学员的困难选择场景归纳或模型应用；不同来源分别记账，不合称统一方法。 |
| 一节课较长、需要连接多个内容块，或有嘉宾 | [长课与讲述编排](单课设计-长课与讲述编排.md)：先排学习单元与反馈，再按需借用有功能的提问、揭示与转场；部分证据来自长直播及嘉宾场。 |
| 用户明确要求体验课、销讲或课程产品承接 | [体验与销讲课](单课设计-体验与销讲课.md)：分别设计当堂教学和可核实的产品说明；不同体验课案例分别记账。普通正式课不自动添加销售。 |
| 只有操作技能练习、反馈或其他未被上面覆盖的目标 | 只用通用底座，按学科补充依据；如需专业安全审核，保留审核与无法落实的条件。 |

## 当前证据边界

- **知识讲解研究 `KNOW-A`**：可支持知识讲解和案例推进的设计借鉴，不能直接认证完整付费单课框架。
- **概念课阅读稿 `KNOW-B`**：可借场景比较、提炼模型与应用回收；不代表其他课程，也未认证原声。
- **讲述编排研究 `TALK-A`**：可作为可选灵感；作者、原始案例拆解及教学成效未核，不把销讲节拍和情绪比例作通用课标。
- **长直播观察 `TALK-B`**：可借主持、嘉宾和回收的职责组织；不能据此宣称覆盖所有正式长课。
- **体验课案例 `TRIAL-A`**：可观察教学与产品说明交替；分析中的时间线与转写不一致，不沿用其时间分配。内容和效果不自动可信。
- **动作课案例 `TRIAL-B`**：可观察复练、反馈、新授及产品说明后继续带练；原音和视频同版待核，不能将课程功效或成交结果当作已证事实。

这些是**按证据可用的教学设计工作参考，不是已完成并验证的作者原版框架**。标识经过匿名化，部分原件不随仓库分发；需要审计时按来源 ID 查找获授权的材料，无法访问时如实说明；没有来源时仅使用已标注的有界设计建议，不把来源推测说成已证事实。
