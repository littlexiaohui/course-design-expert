# 单课设计来源与证据状态

本页记录各类材料可支持的范围。`KNOW`、`TALK` 和 `TRIAL` 是匿名来源标识，不代表人物或机构名称，也不是自动下载地址；不同标识分别记账，不合称同一套原法。部分研究来源为私人材料，不随本技能分发，因此使用者可能无法独立核验。持有合法来源的环境可在仓库外维护“标识 → 路径、哈希、定位、权限边界”映射，并用环境变量 `COURSE_DESIGN_EVIDENCE_MAP` 指向它。映射缺失时可使用本包内的有界设计建议；若用户要求核对原文，须先取得合适授权的来源或明确说明不能核对。不要把私人来源、账号信息、付费原课或大段原文加入公开仓库。

| ID / 来源 | 证据层与可支持的判断 | 主要缺口 |
|---|---|---|
| `CMU-OBJ`、`CMU-ASSESS`：[学习目标](https://www.cmu.edu/teaching/designteach/design/learningobjectives.html)、[评估与目标对齐](https://www.cmu.edu/teaching/designteach/design/assessments.html) | 公开的教学中心方法材料：目标、教学与评估的对齐及按目标选择评估。 | 支持设计原则，不证明具体方案已试教。 |
| `KNOW-A`：知识讲解与材料组织研究 | 支持案例解释和模型调用的设计借鉴。 | 私人研究材料不随包分发；不是完整付费单课框架，也不是本包运行依赖。 |
| `KNOW-B`：一份概念课阅读稿及元数据 | 可观察场景对比、归纳、模型、应用与回题。 | 个人学习权限；阅读稿有疑词及缺口，未认证原音或官方完整性；不推广为整套课程方法。 |
| `TALK-A`：课程结构手册及编排研究 | 二次方法材料支持提出问题、回收和段落桥接等候选动作，其中也含销讲设计。 | 作者、原始案例证据和对课堂的作用未核；固定情绪及销售节奏只是来源说法。 |
| `TALK-B`：长直播预检、连麦写法研究与原件片段映射 | 可为主持、嘉宾交接与回收提供有界观察。 | 不是对所有正式长课的教学验证；部分材料无可靠时码或角色边界，嘉宾观点不归为主持人。 |
| `TRIAL-A`：体验课转写与单课分析 | 可观察教学、服务、产品信息和报名说明等不同功能的出现。 | 分析承认定向采样，其转化时间表与转写不一致；转写和录播是否同版、实际效果未核，医疗主张不能当事实。 |
| `TRIAL-B`：动作体验课转写及二手分析 | 可观察准备、复练、反馈、新授以及产品说明后继续练习；用于辨认段落功能，不复制原课事实。 | 原音、视频同版、实际疗效与成交效果未核。讲者对身体反应的解释不能作为医学结论。 |

本包参考将**可观察的来源组织**与**用于新课程的设计建议**分开。引用仓库内资料使用相对链接；跨仓库来源靠上述 ID 和私有映射，不依赖某个用户的目录结构。迁移时先检查相对链接和包依赖，再决定是否另获授权配置来源；此处不提供任何推送或发布授权。
