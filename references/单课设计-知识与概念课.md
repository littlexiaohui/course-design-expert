# 知识与概念课：选择理解路径

## 适用与输入

适合学员需要理解概念、区分相似概念、用模型分析案例或形成判断的一课。先读[通用底座](单课教学设计通用底座.md)：需要本课终点、学员已有经验与误区、所讲概念/模型的可核事实、一到两个可使用的材料、时间及反馈条件。没有案例就用明确标注的虚构例子做设计演示；专业结论没有来源时不冒充事实。

## 先决定哪里最难

| 学员障碍 | 可选组织决策 | 能看到的学习证据 |
|---|---|---|
| 词很抽象，不知道与自己有什么关系 | 从一个熟悉的具体问题或两种做法比较进入，先让学员指出差别；归纳共同点后再命名、限定概念，回到起始问题解释。 | 学员能用自己的话解释差别并指出判断依据。 |
| 听过模型名称，但不会调用 | 先解释模型解决什么问题、各部分怎么关联；在同一个例子里指出事实对应哪一部分，走出中间判断，再改变一个条件让学员试一次。 | 学员能在新条件下给出理由，不只背出模型构件。 |
| 误以为定义适用于任何情境 | 对比一个正例和一个边界例，指出哪些条件改变了判断；保留真实资料中的不确定性。 | 学员能指出何时不宜使用，或还需要什么信息。 |

以上是按本课困难选择的**设计方案**，并非必须执行的三个阶段。比如只有 30 分钟且目标是分清一个概念，可用“具体对比 → 命名并解释 → 新例判断与反馈”；若目标是会用模型，则可用“模型用途与关系 → 老师做一例 → 学员做一例 → 对照依据”。按底座给出实际材料、示范、问题与反馈；不能只有环节名。

## 借鉴从哪里来

- **知识讲解研究 `KNOW-A`**：从理解障碍选择材料链、让模型在具体对象上参与推理。研究材料不是本参考的运行依赖。把它扩展成有练习和反馈的完整单课，是本项目的设计建议，不是对完整付费单课结构的认证。
- **概念课阅读稿 `KNOW-B`**：现有阅读稿先介绍多个对比，再归纳共性、给出模型，后续讨论应用并回到开场问题。这里只观察这一稿的组织，建议使用“对比—归纳—命名—应用”时应按用户的目标和事实重做，不移植原课案例、主张或作业；原音、全课完整性及普适效果未认证。

来源 ID 与状态见[证据状态](单课设计来源与证据状态.md)。如果用户指定必须忠实使用某位讲师完整原法，先核对应原件；缺失时报告已知和待核范围，不能把上述设计建议冒充原话或原法。
