## 🔄 完整工作流演示

### **场景:设计一门新课程**

**第1步 - ProjectA【知识封装】**
```
我: 我想封装"课程设计五步法"
AI: [生成课程设计助手提示词]
我: [下载保存]
```

**第2步 - ProjectB【课程设计】**
```
我: 调用课程设计助手,我想做"AI提效"培训
AI: [按实际信息缺口进行必要提问，并依现行 Skill 处理路线选择]
我: [回答问题]
AI: [输出完整课程大纲]
我: 帮我生成"待审视版本"(按标准模板)
AI: [生成标准输出文件]
我: [复制全文]
```

**第3步 - ProjectC【决策假设】**
```
我: [粘贴刚才的文件]
我: 请审视这个方案
AI:
核心假设:
1. 假设目标学员真的"不知道AI能干啥"(而非"知道但不会用")
2. 假设5个场景就能覆盖他们80%的需求
3. 假设3小时课程足够让他们从0到上手
...

潜在风险:
[高风险] 目标学员可能已经试过AI,只是没用好
[中风险] 5个场景可能不够,学员会觉得不过瘾
...

前测建议:
第1步(成本<100元):做10人问卷,验证假设1
第2步(成本<500元):开1场免费试听会,验证假设2和3
第3步(成本<2000元):做20人小规模首发,收集完整反馈
...

我: [根据报告调整方案]
```

**第4步 - 回到ProjectB优化**
```
我: 根据决策审视报告,我需要调整课程:
- 目标学员改成"试过AI但没用好"的人
- 场景从5个增加到8个
- 课时从3小时调整到4小时
...

AI: [帮你重新生成优化版大纲]
```

## 🎯 三个Project的定位总结

| Project | 核心功能 | 复用频率 | 典型产出 |
|---------|---------|---------|---------|
| **A-知识封装** | 把学到的知识封装成助手 | 中频(每周1-2次) | 决策助手提示词 |
| **B-课程设计** | 用助手完成课程设计 | 高频(每月2-5次) | 完整课程大纲 |
| **C-决策假设** | 审视任何业务方案 | 高频(每周1-3次) | 决策审视报告 |
