# 课程五要素：设计时的操作摘要

本摘要服务于现行 [课程设计 Skill](../SKILL.md)，用于从课程目标推导课程体系；具体顺序、授权和交付范围均以主入口为准。它是工作用的归纳，不是对任何一篇来源文章的逐字复刻。

## 三种常见课程任务

- **技能学习**：学员需要在具体任务中做出判断或完成操作，安排相应的示范、练习与可落实的反馈。
- **认知拓展**：学员需要理解、比较或重新看待问题，按目标选择解释、提问、案例或反思，不强制配置作品或人工批改。
- **体验与转化**：在已经授权产品承接时，体验课先交付清楚约定的学习内容，再如实说明后续产品；正式课、体验课及其服务不得混为同一承诺。

一门课可以同时具备多种功能；先看实际学习目的和资源，不按名称机械归类。

## 五个要素怎样共同工作

| 要素 | 设计时要回答 | 与其他要素的关系 |
|---|---|---|
| 起点 | 学员当前的生活或工作场景、期待、经验、能力和未知是什么？ | 决定目标跨度与先修；参加过前课不等于已掌握。 |
| 终点 | 希望学员获得什么有意义的变化，以及可观察的能力、行为或成果是什么？ | 用适合课型的证据了解达成，不把预期效果当保证。 |
| 交付体系 | 为达到终点，哪些知识和能力必须练到什么程度，哪些只需了解？ | 强交付要有内容、标准与验证；弱交付也需明确触达位置。 |
| 服务体系 | 练习、解答、反馈或自查由谁在何时以什么方式提供？ | 应与真实人数、师资、平台和已售承诺匹配；不能假定逐人反馈。 |
| 时间体系 | 总周期、课次、单课时长和学员投入怎样安排？ | 结合实际内容、难度、练习与反馈容量判断，不用固定周期或数量套所有课。 |

## 如何落到方案

先整理已知事实、基于材料的判断、建议假设和待核项；五项形成自洽的可审阅工作版本后，按主 Skill 的检查点比较或采用已定组织路线，再设计阶段和逐课框架。回查阶段与课次的起点、终点、先修、强弱交付、验证和反馈是否共同支撑课程终点；设计估算仍需试讲与实际条件核对。
